# Assignment 4: Forms and Validation

Student: Mansur, Group: SE-2527

## Description
Static website with HTML forms, HTML5 validation and Bootstrap 5.3 validation feedback.
All pages share the same navbar linking to every task.

| Page | Content |
|---|---|
| `index.html` | Home page with links to all tasks |
| `task0.html` | Basic contact form (name, email, message, labels) |
| `task1.html` | HTML5 validation (`required`, `minlength`, `maxlength`, `pattern`, `type`) |
| `task2.html` | Contact form with Bootstrap form classes, grid, placeholders and helper text |
| `task3.html` | Bootstrap `is-valid` / `is-invalid` examples + a form where you can try valid and invalid data |
| `task4.html` | Registration form (radio, checkboxes, select, Bootstrap validation feedback, Submit/Reset) |

## Project structure
```
index.html, task0.html ... task4.html
css/style.css     custom styles on top of Bootstrap (no JavaScript is used)
```

## How to run
1. Clone the repository.
2. Open `index.html` in a browser (internet is needed to load Bootstrap from CDN).
